Python Calculator and Unit Converter

About

This project contains two beginner-friendly Python programs.

1. Python Calculator

- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero

2. Unit Converter

- Kilometers to Miles
- Miles to Kilometers
- Kilograms to Grams
- Meters to Kilometers

Technologies Used

- Python

Concepts Learned

- Variables
- User input and output
- Conditional statements
- Arithmetic operations
